# Feature requests

Proposed solver functionality for JPlateSolve, coordinated with SpacePixels. Current behavior is described in [README.md](README.md); design work is in [DESIGN-IMPROVEMENTS.md](DESIGN-IMPROVEMENTS.md).

A request is a proposal until the maintainer decides on it. Remove requests when implemented or closed; describe implemented behaviour in README.md, and use git history for the proposal and its reviews. The completed blind-solve scope of JP-03 and JP-06 is described in the README's [JP-03](README.md#jp-03-make-online-blind-solve-requests-unambiguous) and [JP-06](README.md#jp-06-improve-blind-solve-reliability-and-remove-unused-annotations) sections.

## Current scope

No open feature requests remain. The maintainer confirmed on 2026-11-02 that both JPlateSolve and SpacePixels provide blind solving only. Custom/near solving is outside the current scope; revisiting it requires a new proposal and decision.
